# docs/design · 文档地图

Navigator 设计文档按**版本目录**组织：一版一快照，旧版冻结、当前版活。

## 版本树

```
docs/design/
├── README.md            ← 本文档（文档地图 + 当前版本指针）
├── v0.0.9/              （存档）DevConsole 草案——四套旧工具缝合时代的遗留，概念已被推翻
│   ├── prd.md
│   └── assets/          4 张架构 SVG（仅此版使用）
├── v0.1.0/              （存档）Navigator 第一版 PRD + 首批用户故事
│   ├── prd.md
│   └── user-story.md
├── v0.1.1/              （存档）Spark 术语引入、分层验收模型（任务自验 → 目标验收 → 合并）、实体与关系
│   └── prd.md
└── v0.1.2/              ★ 当前活版本
    ├── prd.md           主干：定位 / 术语 / 实体与关系 / 架构 / 里程碑 / 待决策（详细设计见 specs）
    ├── user-story.md    用户故事（人话验证设计）
    └── specs/           详细设计，按主题各一份
        ├── spark-board-design.md
        ├── goal-story-card-design.md
        └── m0-implementation-steps.md
```

## 当前活版本：v0.1.2

改动只在 `v0.1.2/` 内进行；升版 = 把 `v0.1.2/` 整体复制成 `v0.1.3/` 再改，旧目录冻结。

## 文档角色

| 文档 | 读者 | 看什么 |
|---|---|---|
| `v0.1.2/prd.md` | 评审/拍板 | 产品是什么、边界、里程碑、待决策；详细设计只看摘要+去 specs |
| `v0.1.2/user-story.md` | 人 | 用故事检验设计讲不讲得通 |
| `v0.1.2/specs/*` | 实现 | 字段级/流程级/UI 级细节 |

## 每版要点速览

- **v0.0.9**：DevConsole——缝合 dev-loop/loopx/schedule-task/cumora 的旧想法。教训：大杂烩不是产品描述。
- **v0.1.0**：确立 Navigator（中枢、自托管 VPS、多机 worker）；用户故事成文；术语表独立成章。
- **v0.1.1**：Spark 取代"意见"；实体与关系独立成节；分层验收模型（任务自验→目标验收→合主分支）；连通层（WS 隧道 + ACP + MCP）；零原生脑。
- **v0.1.2**：故事板敏捷借鉴（目标=故事卡）；Spark 详细设计（生命周期/汇总分类/无强制标签）落 specs；M0 实施步骤成文；文档按版本目录组织。

## 版本语义

- 版本号遵循 `v0.1.x` 草稿节奏，到 M0 可跑后考虑 `v1.0`。
- git 管"每次改动"，版本目录管"里程碑快照"，两者互补。
